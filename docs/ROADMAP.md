# Roadmap

The actionable queue is now [PLAN.md](PLAN.md). Start each session with [STATUS.md](STATUS.md); repository [AGENTS.md](../AGENTS.md) defines the compact execution workflow.

Order: saved sessions and recovery → diagnostics → measured evaluation → Windows packaging → keyboard/accessibility work → optional GPU support.

Each "continue" completes one ready task, validates it, updates the progress record, and commits/pushes the checkpoint. Sessions use actual work dates and require the user to start them; no unattended daily job is configured.
