# LumaCaption

A Windows desktop workspace for turning photos into editable captions, entirely on your computer after a one-time model download.

LumaCaption is a new application written from scratch. It uses Salesforce's pretrained BLIP captioning model; it does **not** claim to have trained that model. The tutorial's source files, Flickr8k dataset, and generated artifacts are not part of this project.

Implementation and Windows verification are in progress. See [the progress log](docs/PROGRESS.md).

Planned: native image previews, editable captions, batch processing, CPU inference, offline mode, CSV/JSON export, and a command-line interface.
